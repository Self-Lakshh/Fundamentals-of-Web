## 🏆 Milestone Deep Dive

### 🏷️ Milestone 1: HTML Fundamentals (Days 1–5)
*Focus: Document scaffolding, structure, forms, tables, and SEO-friendly semantic layouts.*
*   **Key Learnings**: Understood the browser document object tree (DOM), the structural differences between block vs inline elements, form data validation rules, and the accessibility benefits of semantic markers like `<article>` and `<section>`.

### 🎨 Milestone 2: CSS Fundamentals (Days 6–12)
*Focus: Typography, advanced selectors, box-model spacing, Flexbox, CSS Grid, animations, and responsive breakpoints.*
*   **Key Learnings**: Mastered CSS Grid for complex 2D page layouts and Flexbox for 1D content alignment. Built keyframe-based hero slide transitions and verified responsive design scaling across standard screen viewports (mobile, tablet, desktop).

### ⚡ Milestone 3: Bootstrap 5 Layouts (Days 13–18)
*Focus: Utilizing helper utilities, components (carousels, cards, grids, navs), and custom overrides.*
*   **Key Learnings**: Gained rapid prototyping skills using Bootstrap's utility classes and container patterns. Overrode default component styles to match custom color systems and layout spacing.

### ⚙️ Milestone 4: JavaScript Core Interactivity (Days 19–25)
*Focus: DOM manipulation, events listening, state management, calculations, local storage caching, and UI updating.*
*   **Key Learnings**: Created lightweight widgets and application states utilizing `localStorage` caching (saving user-selected UI themes and list planning states). Structured event triggers to toggle UI layouts dynamically.

### 💎 Milestone 5: Final Resume & Portfolio Website (Days 26–30)
*Focus: Assembling all previous technologies into a premium, responsive multi-section portfolio.*
*   **Key Highlights**:
    *   **Modern Aesthetics**: Styled using beautiful radial gradient backgrounds, frosted-glass header navbar glassmorphism (`backdrop-filter: blur`), and clean Outfit typography.
    *   **Data-Driven UI**: Projects are stored in a JavaScript array object and dynamically loaded into the DOM using an injection script, avoiding boilerplate HTML duplication.
    *   **Dynamic Features**: Responsive layouts optimized down to `320px` viewports, responsive sidebar overlays for mobile sizes, and secure feedback forms.

## 🚀 How to Run locally

Since all projects are built using native web technologies (HTML, CSS, JS), you can run them directly in your browser without complex build tools:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Self-Lakshh/Fundamentals-of-Web.git
    cd Fundamentals-of-Web
    ```
2.  **Open any Day's project**:
    *   Simply open the `index.html` file inside any daily folder (`Day-01` to `Day-30`) in your favorite browser.
    *   *Alternative*: Use the VS Code **Live Server** extension or run a lightweight local server:
        ```bash
        # Run a simple static file server
        npx serve .
        ```
